                                             PROJETO EDN - Mini PDV (Ponto de Venda) 
Criar um programa que registre as compras de um cliente, calcule o total e aplique descontos baseados em regras específicas.

Requisitos do Sistema:

O programa deve perguntar o nome do produto e o preço.

(Estrutura de Repetição)

Deve perguntar se o usuário quer adicionar mais itens .

(Regra de Negócio)

No final, se o valor total for maior que R$ 100,00, deve aplicar 10% de desconto,
