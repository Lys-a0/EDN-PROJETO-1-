🚀 MINI PDV - Ponto de Venda

Descrição:

Sistema simples de ponto de venda que registra compras de clientes, calcula o total automaticamente e aplica descontos baseados no valor da compra. Ideal para pequenos negócios que precisam de um controle básico de vendas.


🔨 Funcionalidades

-> Funcionalidade 1: Cadastro de produtos
Permite adicionar vários itens à compra, informando nome e preço de cada produto, com repetição até que o usuário finalize a lista.

-> Funcionalidade 2: Cálculo de desconto automático
Aplica 10% de desconto automaticamente quando o valor total da compra ultrapassa R$ 100,00, exibindo o valor original, o desconto e o valor final.

-> Funcionalidade 3: Resumo da compra
Mostra todos os itens adquiridos e o valor total formatado, facilitando a visualização para o cliente.
